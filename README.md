## Projetos em destaque

### Virada
Treinador de xadrez em português que analisa partidas do chess.com com o Stockfish rodando no próprio aparelho, sem cadastro e sem servidor. Classifica cada lance, explica os erros, gera exercícios com repetição espaçada e funciona offline como PWA.
React, TypeScript, Vite, Tailwind CSS, WebAssembly, Web Workers, IndexedDB.
[Repositório](https://github.com/Joaopedrotavaress/virada) · [Aplicação](https://virada-kappa.vercel.app)

### Lord Pets, loja virtual
Loja virtual para uma rede de pet shops de Belo Horizonte, com vitrine de produtos, estoque por unidade e pedido pelo WhatsApp, integrada ao ERP Bling (OAuth, sincronização e webhooks). Arquitetura em módulos, com testes de integração em banco real e testes de ponta a ponta.
.NET 10, Blazor, Entity Framework Core, PostgreSQL, Testcontainers, Playwright.
Repositório privado.

### Manutenção e vulnerabilidades em dependências .NET
Projeto de pesquisa em equipe que relaciona a atividade de manutenção de projetos open source em .NET com a presença de vulnerabilidades em dependências NuGet, incluindo eventos de atualização e technical lag. O analisador coleta e processa os dados de 30 projetos.
Java 21, Spring Boot, Docker, API do GitHub.
PUC Minas, Projeto Interdisciplinar.

### TaskManager API
API REST para gerenciamento de usuários e tarefas, com consultas por usuário, status e período via LINQ e documentação interativa com Swagger.
.NET 8, C#, Entity Framework Core, MySQL.
[Repositório](https://github.com/Joaopedrotavaress/TaskManager)
